🏦 Banking System (Python CLI Project)

A simple command-line banking system written in Python.
This project was created for practice while learning Python fundamentals such as functions, loops, and input validation.

📌 Features

View current balance

Deposit money

Withdraw money

Prevent invalid input

Prevent withdrawing more than balance

Loop-based menu system

Clean terminal interface

🧠 Concepts used

Functions

While loops

Conditionals (if / elif / else)

Global variables

Input validation

Python standard library (time)

▶️ How to run

Install Python 3

Download the file

Run in terminal:

python banking_system.py
📋 Menu Options
1 -> View balance
2 -> Deposit money
3 -> Withdraw money
4 -> Quit program

The program keeps running until the user selects Quit.
